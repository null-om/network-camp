The basics

A new laptop joins a network. How can other devices identify and communicate with it?

An IP address is a logical address assigned to a network interface, allowing devices to be identified and addressed within an IP network.

Binary & IPv4

  • Binary uses only two digits: 0 and 1.
  • A bit is one binary digit.
  • An IPv4 octet is 8 bits.
  • Each bit position has a decimal value. Add up the positions set to 1.

An IPv4 address is four octets: 4 × 8 bits = 32 bits

Why binary? It is the key to understanding subnet masks, separating network and host portions, and subnetting calculations.

Classful addressing

IPv4 Address Classes

Value of the first octet, 0 to 255

ClassFirst octet rangeDefault subnet mask
A1–126255.0.0.0
B128–191255.255.0.0
C192–223255.255.255.0
D224–239Multicast
E240–255Experimental / Reserved
  • The traditional class system is called classful addressing.
  • Focus on A, B and C: they have a default subnet mask and traditional network roles.
  • Class D is associated with multicast. Class E is reserved for experimental purposes.

127 is reserved for loopback, which is why Class A stops at 126.

Network part vs. host part

Subnet Mask: Network Part vs. Host Part

A subnet mask is a 32-bit value used to distinguish the network portion of an IPv4 address from the host portion.

IP ADDRESS192.168.1.10 SUBNET MASK255.255.255.0 MASK IN BINARY11111111111111111111111100000000 Network part: 192.168.1Host part: 10
Bits set to 1

Represent the Network portion.

Bits set to 0

Represent the Host portion.

CIDR prefix notation

255.255.255.0 = /24
/24 means 24 network bits.
