Two kinds of address

  • The traditional class system is called classful addressing.
  • Focus on A, B and C: they have a default subnet mask and traditional network roles.
  • Class D is associated with multicast. Class E is reserved for experimental purposes.

127 is reserved for loopback, which is why Class A stops at 126.

Number systems

Binary & IPv4

  • Binary uses only two digits: 0 and 1.
  • A bit is one binary digit.
  • An IPv4 octet is 8 bits.
  • Each bit position has a decimal value. Add up the positions set to 1.

Network part vs. host part

Subnet Mask: Network Part vs. Host Part

A subnet mask is a 32-bit value used to distinguish the network portion of an IPv4 address from the host portion.

IP ADDRESS192.168.1.10 SUBNET MASK255.255.255.0 MASK IN BINARY11111111111111111111111100000000 Network part: 192.168.1Host part: 10
Bits set to 1

Represent the Network portion.

Bits set to 0

Represent the Host portion.

CIDR prefix notation

255.255.255.0 = /24
/24 means 24 network bits.

Network boundaries

Two devices have different IP addresses. Does that mean they belong to different networks?

Not necessarily. The answer depends on the subnet mask, not on whether the IP addresses differ.

Why subnetting?

What happens when a network becomes too large to manage as one network?

Subnetting divides one larger IP network into multiple smaller logical networks.

01

Better organization

Group devices into logical segments by department, location, or purpose.

02

Efficient address use

Divide the address space into right-sized networks instead of one oversized range per group.

03

Reduced broadcast scope

Smaller subnets help keep broadcast traffic inside each segment.

04

Easier management

A clearer structure is easier to understand, administer, and troubleshoot.

Now that we understand why networks need to be divided, let’s learn how subnetting actually works.

Subnetting

How Subnetting Works

Classful → classless

Classes A, B and C used fixed default network boundaries. Modern networks use CIDR (Classless Inter-Domain Routing), where the prefix length is flexible, so we can divide address space into subnets that fit actual needs.

The core idea

Subnetting is the process of dividing a larger IP network into multiple smaller logical networks.

  • An IPv4 address has a network portion and a host portion; the subnet mask sets the boundary.
  • Subnetting borrows bits from the host portion and uses them as extra network bits.
  • Result: more subnets, but fewer host addresses in each.
