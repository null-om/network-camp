Concepts

What is a router?

A router connects different networks and decides where each packet goes next.

Connects networks

Links one LAN to another, or a LAN to the Internet.

Reads IP addresses

Looks at the destination IP of every packet it receives.

Chooses the path

Uses its routing table to pick the next hop.

Concepts

Rule of thumb: switches build a LAN, routers connect LANs.

How a packet travels

R2Router
PC2192.168.2.10
  1. PC1 sees that PC2 is in another network, so it sends the packet to its default gateway, R1.
  2. R1 checks its routing table and forwards the packet to the next hop, R2.
  3. R2 sees that PC2 is directly connected and delivers the packet.
Concepts

The routing table

R1's routing table lists the networks it can reach and how to get there.

Destination networkNext hopExit interface
192.168.1.0/24Directly connectedG0/0
10.0.0.0/30Directly connectedG0/1
192.168.2.0/2410.0.0.2G0/1

No matching entry? The router drops the packet, unless it has a default route.

Concepts

Default gateway

The default gateway is the router address a PC uses to leave its own network.

Destination in my network

The PC sends the packet straight to the destination.

Destination in another network

The PC sends it to the default gateway, which is the router.

PC1 settingsIP address 192.168.1.10 Subnet mask 255.255.255.0 Default gateway 192.168.1.1
Routing types

Two ways to build a routing table

Static routing

You type every route by hand.

  • Best for small, simple networks
  • Predictable and easy to read
  • No automatic backup path

Dynamic routing

Routers learn routes from each other.

  • Protocols: RIP, OSPF, EIGRP
  • Best for larger networks
  • Adapts when a link fails
Routing types

Static routes

R1(config)# ip route 192.168.2.0 255.255.255.0 10.0.0.2
192.168.2.0

The network you want to reach

255.255.255.0

Its subnet mask

10.0.0.2

The next hop: the neighbor router's IP

Always point to the neighbor's address, never your own.

Routing types

Default route

R1(config)# ip route 0.0.0.0 0.0.0.0 10.0.0.2

Matches everything

0.0.0.0 0.0.0.0 means any network. It is used only when nothing more specific matches.

Shows as S*

In show ip route, a static default route is marked S*.

One way out

Best for small networks with a single path, such as the link to the Internet.

Routing types

Dynamic routing: RIP

RIP is the simplest routing protocol, so it is a good first example.

  • Distance-vector protocol
  • Metric is hop count (maximum 15)
  • Sends updates every 30 seconds
  • Use version 2 on modern networks
R1(config)# router rip R1(config-router)# version 2 R1(config-router)# no auto-summary R1(config-router)# network 192.168.1.0 R1(config-router)# network 10.0.0.0

R2 does the same, advertising 192.168.2.0 and 10.0.0.0.

Routing types

Administrative distance (AD)

Route sourceAD
Directly connected0
Static route1
EIGRP90
OSPF110
RIP120

Lower is better

If RIP and a static route both reach the same network, the static route (AD 1) wins.

Configure the interfaces

Connect the devices with copper cross-over cables, then open each router's CLI tab.

Wrap-up

Troubleshooting and recap

If the ping fails, check

  • Interfaces are up (no shutdown)
  • IP addresses and masks are correct
  • Both routers have a route to each LAN
  • PC default gateways are set
  • Cables are in the right ports

Key takeaways

  • A router forwards packets using its routing table
  • Static routes are typed by hand, dynamic routes are learned
  • The lowest administrative distance wins
  • show ip route is your best friend
